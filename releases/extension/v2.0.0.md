# JavdBviewed 浏览器扩展 2.0.0

2.0.0 是浏览器扩展的固定 ID 主版本。它通过 Release ZIP 自托管安装，不提交 Chrome Web Store。

## 下载

- 文件名：`javdb-extension-v2.0.0-build-118.zip`
- SHA-256：`81E06AF29699A47469A4BF1B34E88A4CC0FBC2D25F0D64C25F15489DDC752AED`

## 升级前请先备份

Chrome 不会把旧 1.x 扩展 ID 的本地数据自动迁移到 2.0.0。安装前请在旧版扩展中打开“备份与恢复”，选择“导出 ZIP 备份”，并确认备份文件已经保存。已配置 WebDAV 时，再上传一份云端 ZIP 作为兜底。

在确认 2.0.0 已完成导入和检查前，请保留旧版扩展，不要卸载旧版或清理浏览器扩展数据。

## 安装与导入

1. 下载并解压 ZIP 文件。
2. 打开 `chrome://extensions/` 或 Edge 的扩展管理页。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，载入解压后的目录。
4. 打开 2.0.0 的“备份与恢复”，选择“导入本地备份”，优先导入 ZIP；历史 JSON 备份也兼容。
5. 在导入预览中确认备份版本和数据范围，再确认恢复。
6. 检查番号库、观看记录、演员库、清单和设置；确认正常后再移除旧版扩展。

完整使用说明见[文档站](https://docs.we-together.club/)，问题反馈请提交到[JavdBviewed Issues](https://github.com/JavdBviewed/JavdBviewed/issues)。请不要在公开 Issue、截图或日志中附带密码、令牌、API Key 或备份文件。

## 导入失败时怎么办

- 不要卸载旧版扩展，不要清理浏览器数据，也不要在 2.0.0 中执行重置操作。
- 回到旧版扩展重新导出一份 ZIP 备份，再检查文件是否完整；如果本地文件不可用，再配置 WebDAV 恢复云端 ZIP。
- 重新安装 2.0.0 后再次导入；损坏或不兼容的备份应由导入结果明确提示失败。

## 回滚

回滚前先关闭 2.0.0 的管理面板，保留 2.0.0 当前导入文件和操作记录。重新加载旧版扩展目录，使用旧版原有数据继续工作；如需再次尝试升级，先从旧版重新导出备份。

不要通过删除 Chrome 配置目录来回滚，这可能同时删除旧版扩展仍在使用的数据。
