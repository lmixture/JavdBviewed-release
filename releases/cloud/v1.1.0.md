# Cloud 1.1.0 正式发布

Cloud 1.1.0 现已作为正式稳定版本发布。本版本重点完善实例运行观测和发布构建信息，方便管理员确认实例状态与版本来源。

## 主要变化

- 完善 Cloud 实例运行状态和聚合统计的后台观测能力。
- 将运行版本号与构建标识分开显示：版本号使用 SemVer（例如 `1.1.0`），构建标识保留 `git-<short-sha>` 以便定位源码。
- 修复发布构建在受支持的 Go 版本范围内的测试兼容性。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请在管理台创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

默认模板使用 `latest`，会获取最新正式镜像。需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.1.0
```

本版本镜像 digest：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.1.0@sha256:100679a40b6696fbe993beb5ec336f1ea4bcf9aeace55c4c368351247120bc86
```

## 新部署

推荐使用 Docker Compose 部署。请先准备好 Docker 和 Docker Compose，再按[部署指南](https://docs.we-together.club/download/#cloud-deploy)完成配置。生产环境请设置强随机的 `CLOUD_JWT_SECRET`，并通过 HTTPS 反向代理暴露服务。

## 启动后检查

服务启动后，打开 Cloud 管理台完成登录，并确认设备可以正常连接和同步。也可以访问 `/health` 检查服务是否可用；访问 `/version` 可确认 `version` 与 `buildNumber` 已分别记录。

使用或部署中遇到问题，请先查看[Cloud 部署指南](https://docs.we-together.club/download/#cloud-deploy)，再到 [JavdBviewed Issues](https://github.com/JavdBviewed/JavdBviewed/issues) 提交问题。请勿在公开内容中附带密码、令牌、数据库或快照文件。
