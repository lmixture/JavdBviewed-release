# Cloud 1.2.0 正式发布

Cloud 1.2.0 现已作为正式稳定版本发布。本版本重点整理管理台的信息架构，降低管理员定位数据、同步和审计信息的成本。

## 主要变化

- 重整管理台设置页，按账号与权限、系统、数据与同步、版本与更新等职责分类展示。
- 数据管理页增加“数据概览”“同步数据”“快照管理”分类，减少长页面堆叠。
- 将同步会话归入审计页面，审计页统一提供操作记录与同步会话两个分类。
- 保留旧的同步会话地址兼容跳转，不需要重新登录或重新配置 Cloud。
- 清理设置页中的发布源、构建状态、宿主机路径等内部实现信息，避免向管理员暴露不必要的部署细节。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请先在管理台的数据页面创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

默认模板使用 `latest`，会获取最新正式镜像。需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.0
```

本版本镜像 digest 以本发布说明中的固定镜像地址为准；部署后请访问 `/version`，确认 `version` 为 `1.2.0`，并核对 `buildNumber` 与发布清单中的 commit。

## 新部署

推荐使用 Docker Compose 部署。请先准备好 Docker 和 Docker Compose，再按[部署指南](https://docs.we-together.club/download/#cloud-deploy)完成配置。生产环境请设置强随机的 `CLOUD_JWT_SECRET`，并通过 HTTPS 反向代理暴露服务。

## 启动后检查

服务启动后，打开 Cloud 管理台完成登录，确认数据分类、审计分类和设备同步状态正常。也可以访问 `/health` 检查服务是否可用，访问 `/version` 确认版本与构建标识。

使用或部署中遇到问题，请先查看 [Cloud 部署指南](https://docs.we-together.club/download/#cloud-deploy)，再到 [JavdBviewed Issues](https://github.com/JavdBviewed/JavdBviewed/issues) 提交问题。请勿在公开内容中附带密码、令牌、数据库或快照文件。
