# Cloud 1.0.0 正式发布

Cloud 是部署在你自己设备或服务器上的数据服务，用于在 JavdBviewed 的已连接设备之间同步数据。Cloud 1.0.0 现已作为正式稳定版本发布。

## 这次可以使用什么

- 在自己的服务器上运行 Cloud，并使用浏览器扩展连接。
- 在 Cloud 管理台管理登录、已连接设备和数据同步状态。
- 创建、下载和恢复数据快照，为升级或误操作保留恢复点。
- 在管理台查看当前运行版本，并在有新版时手动检查更新。

## 新部署

推荐使用 Docker Compose 部署。请先准备好 Docker 和 Docker Compose，再按[部署指南](https://docs.we-together.club/download/#cloud-deploy)完成以下步骤：

1. 下载 [Compose 模板](https://github.com/JavdBviewed/JavdBviewed-release/blob/main/compose/cloud/compose.yaml) 和[环境变量示例](https://github.com/JavdBviewed/JavdBviewed-release/blob/main/compose/cloud/.env.example)。
2. 复制环境变量文件为 `.env`，填写强随机的 `CLOUD_JWT_SECRET`。
3. 执行 `docker compose -f compose.yaml up -d` 启动服务。
4. 首次登录使用账号 `admin`；如果没有预设密码，请从首次启动日志取得一次性临时密码。

完整说明包含端口配置、HTTPS 反向代理、备份、恢复与常见问题。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请在管理台创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

默认模板使用 `latest`，会获取最新正式镜像。需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.0.0
```

然后再次执行上面的两条 Compose 命令。恢复数据时，可使用升级前创建的快照或 `data/` 目录备份。

## 启动后检查

服务启动后，打开 Cloud 管理台完成登录，并确认设备可以正常连接和同步。也可以访问 `/health` 检查服务是否可用。

使用或部署中遇到问题，请先查看[Cloud 部署指南](https://docs.we-together.club/download/#cloud-deploy)，再到 [JavdBviewed Issues](https://github.com/JavdBviewed/JavdBviewed/issues) 提交问题。请勿在公开内容中附带密码、令牌、数据库或快照文件。
