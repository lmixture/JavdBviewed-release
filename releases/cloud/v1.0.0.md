## 新增

- Cloud 管理台提供版本与更新信息，可手动检查 stable 更新。
- 更新清单由本仓库托管，Cloud 内置官方主源。
- 自部署环境可通过 `CLOUD_UPDATE_MANIFEST_MIRRORS` 设置一个或多个完整的清单镜像 URL，用于网络加速或私有网络转发。
- `/version` 与 OCI image labels 提供版本、提交、构建号和发布通道，方便追踪镜像来源。

## 升级与回滚

Cloud 不会自动拉取、替换或重启你的容器。升级前请在管理台创建快照，并备份宿主机 `data/` 目录。

使用 Compose 部署时，先把 `CLOUD_IMAGE_NAME` 设为目标 tag，再执行：

```bash
docker compose pull cloud
docker compose up -d --no-build cloud
```

启动后访问 `/health` 和 `/version`，确认版本、提交与清单一致。发生问题时，把 `CLOUD_IMAGE_NAME` 改回上一个已验证 tag，执行同样的命令；需要恢复数据时，使用升级前的快照或备份。
