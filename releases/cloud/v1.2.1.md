# Cloud 1.2.1 正式发布

Cloud 1.2.1 现已作为正式稳定版本发布。本版本补充管理台中面向用户的帮助与社区入口。

## 主要变化

- 设置页增加帮助文档入口：<https://docs.we-together.club/>。
- 设置页增加扩展 GitHub 项目入口：<https://github.com/JavdBviewed/JavdBviewed>。
- 设置页增加 Telegram 群组入口：<https://t.me/javdbviewed>。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请先在管理台的数据页面创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.1
```

本版本镜像 digest：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.1@sha256:68b8c7864c11c7e87923b5a1c457d373bd42a5030d1e759d21ec671a06579454
```

部署后请访问 `/version`，确认 `version` 为 `1.2.1`，并核对 `buildNumber` 与发布清单中的 commit。

## 启动后检查

打开 Cloud 管理台的设置页，确认“帮助与社区”区域中的文档、扩展 GitHub 和 Telegram 链接可用。也可以访问 `/health` 检查服务状态。
